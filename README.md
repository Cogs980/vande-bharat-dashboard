A fully interactive, filterable map and dashboard of all 82 active Vande Bharat Express routes (164+ services) across India as of June 2026 — built as a single self-contained HTML file with zero backend or dependencies.

🔗 Live Demo: (https://cogs980.github.io/vande-bharat-dashboard/)

📸 Preview
Dark-themed interactive map with color-coded routes by region, filterable sidebar, and per-route action links.

✨ Features
🗺️ Interactive Map – All 82 routes plotted as polylines on a CartoDB dark map (Leaflet.js)

🎨 Color-coded by Region – North (Orange), South (Green), East (Blue), West (Amber), etc.

🔍 Live Search – Filter by city name, state, train number instantly

🗂️ 4 Filter Dimensions – Region · Train Type · Coach Formation · Free-text search

📊 Dynamic Stats Bar – Updates route/type counts as you filter

🔴 Live Status Links – Direct links to RailYatri real-time train tracking

📅 Schedule Links – Per-route timetable on RailYatri

🎫 Booking Links – Direct to IRCTC booking

💤 Sleeper Route Highlighted – Howrah–Kamakhya Vande Bharat Sleeper shown with dashed line

📱 Mobile Friendly – Responsive layout works on phones and tablets
